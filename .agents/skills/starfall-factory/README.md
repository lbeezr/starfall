# Starfall factory skill

[SKILL.md](SKILL.md) runs a bounded delivery loop with independent subagents and continuous integration. The [factory contract](../../../docs/AGENT_FACTORY.md) owns task packets, WIP limits, GitHub closure and the trial. The shared helper lives under [scripts](../../../scripts/README.md); this folder contains instructions only.

For creative production, the skill loads the [game-factory study and prompt kit](../../../docs/design/AI_GAME_FACTORY.md): player experience, one playable slice and evidence-led refinement. Tooling and small fixes retain their narrower scope.
