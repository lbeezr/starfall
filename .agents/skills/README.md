# Starfall repo skills

Load the workflow that matches the task: [verify a change](starfall-verify/SKILL.md), [diagnose CI](starfall-ci-triage/SKILL.md), or [audit a bounded area](starfall-maintenance/SKILL.md). Root and local `AGENTS.md` own invariants; [ENGINEERING](../../docs/ENGINEERING.md#verification-by-change) owns check selection.

These instruction-only skills reuse existing scripts. They do not change personal/plugin settings, mandate agents, dispatch CI or authorize delivery. The [maintenance evidence](../../docs/evidence/repo-maintenance-2026-10-19/IMPLEMENTATION.md) records validation and limits.
