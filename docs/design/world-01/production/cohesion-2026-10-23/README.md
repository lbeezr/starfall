# Ribbon Crossing travel identity

**Adopted for development.** Goal [#289](https://github.com/lbeezr/starfall/issues/289) aligns the damaged map bridge with the separated, frayed ribbon ends already visible in Entry and gameplay. Pearl/brass arch, violet cloth, terraces, dormant lamps and the restored selection retain their existing roles.

The exact [prompt, reference roles and measurements](art-prompts.json) identify the generated PNG copied unchanged into the existing runtime asset. The [original source and prompt](../layered-2026-10-20/README.md) remain historical provenance. The runtime PNG is the canonical revised source; no second binary copy is stored here.

The 1254-pixel RGBA canvas, marker, four route ports and logical clearance stay fixed. The measured alpha≥128 pair union changes from `(14,33)`–`(1245,1211)` to `(14,31)`–`(1250,1211)`; `WorldMapArtwork` records that measurement. Rendering and input geometry do not consume `visibleBounds`. The exterior was qualitatively preserved, not pixel-identical.

[Source-bound native checks](../../../../evidence/cohesion-goal-08-travel-identity-2026-10-23/README.md) verify the phone slice and tablet family. Acceptance requires a legible torn gap at normal phone size, independent neighboring repair states on tablet, preserved native selection/Entry cancellation and saved return, and current-rule Begin. Completed-world restored art followed by a fresh damaged Revisit remains intentional. Reject this candidate if the cleft disappears at native size, a matte appears, attachment support fails or journey behavior changes.
