# Stage and location brief template

Copy this into a stage's own README when starting a selected concept. Fill only fields that support the next decision; delete prompts before review. For future restoration stages, the [world atlas](../WORLD_ATLAS.md) supplies approved identities and the [restoration contract](../STARLIGHT_RESTORATION.md) supplies progress/win proposals. Use the [current nightscape contract](night-production-09/README.md) for native scenery boundaries; the [earlier production process](PRODUCTION.md) retains historical platform guidance. Fill restoration fields only when relevant.

## First screen

- **Name / status / owner / date:**
- **Feeling and purpose:** One sentence about what this place is and how arriving there should feel.
- **Current question and next review:** One bounded uncertainty, comparison and decision point.

## Identity and composition

- **Initial need and restored purpose:** What is interrupted at 0%, and what becomes possible at 100%?
- **Transformation storyboard:** Show 0/25/50/75/100% with a stable camera and board; describe the useful change at each checkpoint and the final payoff. These review points are not fixed gameplay thresholds.
- **Goal and contribution:** How does a clear help, what exactly commits completion, and which target/pressure choices remain hypotheses?
- **States and transitions:** Which structural, light, motion, life and sound changes carry progress? Cover ordinary clears, crossing several milestones, quiet modes and a readable settled ending.
- **Round versus world:** State the unit of completion, partial/completed restore, failure/retry and replay behavior; identify unresolved persistence choices.

- **Distinctive silhouette / distant landmark:**
- **Primary and secondary materials / light:**
- **Quiet play surface / HUD safe zones:**
- **Visible arena boundary:** Register the usable platform rim to the shared seven-by-seven perimeter; specify edge/corner clearance for grown stars, contact shadows and full targets. Review empty/full boards and resized native corner taps.
- **Depth planes and foreground occlusion:**
- **Signature elements and optional prop taps:** Choose a few elements serving the transformation. For interactive props, describe full native target, response, quiet-mode feedback and cancellation; prop taps do not award progress.
- **One or two ambient motifs:** Describe movement range, pause/quiet behavior and why it supports the mood.
- **Actual-cast checks:** All restoration states with empty, sparse, dense, grown/Dusk and grayscale. Link reviewed images; label concepts versus native captures.
