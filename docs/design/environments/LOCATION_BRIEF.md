# Location brief template

Copy this into a location's own README when starting that place. Fill only fields that support the next decision; delete prompts before review. The [production process](PRODUCTION.md) owns shared acceptance and runtime contracts.

## First screen

- **Name / status / owner / date:**
- **Feeling and purpose:** One sentence about what this place is and how arriving there should feel.
- **Current question and next review:** One bounded uncertainty, comparison and decision point.

## Identity and composition

- **Distinctive silhouette / distant landmark:**
- **Primary and secondary materials / light:**
- **Quiet play surface / HUD safe zones:**
- **Visible arena boundary:** Register the usable platform rim to the shared seven-by-seven perimeter; specify edge/corner clearance for grown stars, contact shadows and full targets. Review empty/full boards and resized native corner taps.
- **Depth planes and foreground occlusion:**
- **Two signature props:** Describe appearance, full native target, response, quiet-mode feedback and cancellation behavior.
- **One or two ambient motifs:** Describe movement range, pause/quiet behavior and why it supports the mood.
- **Actual-cast checks:** Empty, sparse, dense, grown/Dusk and grayscale. Link reviewed images; label concepts versus native captures.

- **Assets / editable source or exact prompts / license provenance:**
- **Canvas, alpha bounds, anchors and registration owner:**
- **Reuse versus location-specific behavior:**
- **Fixture, command, source identity and target membership:**
- **Results / failed or unrun cases:** Separate core/save, build, native interaction, visuals, full motion, accessibility and device profile.
- **Decision / remaining risk / trigger and verification:** Adopt, revise, remove, or extend with a bounded next question.
