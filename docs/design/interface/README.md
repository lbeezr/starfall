## Game UI concept — October 19

[`observatory-game-ui-concept-2026-10-19.png`](observatory-game-ui-concept-2026-10-19.png) is the user-approved direction for the [game UI system](../GAME_UI_SYSTEM.md). Built-in ImageGen generated it from `App/Assets.xcassets/LanternLanding100.imageset/scene.png`, the native `dev-caa0c5f__lantern-000__iphone-17e__default-text.png` capture, and `App/Assets.xcassets/WorldMapRestored.imageset/world-restored.png`.

**Generation brief:** A three-screen premium portrait game concept: scenic observatory home with Story Mode / Free Play / Tutorial; a tiny top-safe-edge score, comet forecast and pause HUD; a bottom-anchored settings instrument with Sound / Haptics / Calm effects. Match the existing lantern, brass, clouds and crystal cast. Use tactile midnight enamel, precise brass edges, custom emblems and restrained depth. Keep active play's center clear; omit large HUD/dialogue panels, shops, currencies and web-style lists. The source image was `exec-ef9e6501-2021-45a6-9f48-f61312c8d669.png`; this copy is unchanged.

The earlier HTML/editorial mock was rejected as too website-like. This image establishes art direction only; the system plan owns reusable assets, native controls, adaptive layout and future acceptance. It is not packaged in the app.
