## Bounded integration

`StarfallExperimentScene` owns the presentation. Incoming IDs select left/right drift and one of two angles without consuming core randomness. Dark stars rebound 0.045 cells, growing stars 0.09, ordinary stars 0.18; tangential rebound follows the incoming direction. Edge-column ingress comes from outside that edge. Each survivor gets at most one radial kick from the nearest cleared cell within three cells; distance delays arrival and reduces strength. Clears worth five or more have a stronger pulse; grown/dark survivors resist it. Source ordering resolves equal-distance ties reproducibly. No recoloring, collision outcome, extra score, cascade or save/schema change.

The wave returns to its original position before the 260 ms gravity phase; settling ends at 460 ms and clear input resumes at 480 ms. Arrival rebound lasts 280 ms. Effects reuse existing bounded nodes/materials. Render/restart/settings/background replacement removes scene actions and detached effect/piece nodes; store generation guards remain authoritative. Calm effects, system Reduce Motion and VoiceOver take the existing settled path with a short input gate. No geometry or native accessibility-cell mapping change.

Research: Glenn Fiedler's [Spring Physics](https://gafferongames.com/post/spring_physics/) describes damping, different collision-response weights and restoring equilibrium. This implementation uses bounded authored actions inspired by those principles, not a runtime rigid-body simulation or a numerical spring integrator. That keeps the committed board authoritative and the stop time explicit.

Decision: integrate this small presentation pass without a permanent pilot flag. Do not adopt the separate supernova recoloring experiment. Next decision point is a short human/device comparison: retain or reduce the wave/rebound amplitudes based on perceived impact versus distraction. Simulator samples establish behavior, not enjoyment or frame pacing on hardware.
