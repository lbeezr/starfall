# Crystal Comet celebration material

The original neutral title cutouts and twelve-glyph atlas are now retained under `retired-v1/Celebration*.imageset/`. They were replaced in the app by the user-approved [crystal-depth alphabet](../CrystalComet/NATIVE.md). [Retirement mapping](retired-v1/retirement.json) records former paths, byte hashes and Git recovery provenance; this historical payload inherits this README. [Generation records](generation.json) preserve the original exact prompts and historical packaged paths without rewriting their evidence.

Five historical title images contain their own exclamation marks. `CelebrationGlyphs` contains row-major `0123456789+-`; its 1448×1086 source used four 362-pixel columns and optical row registrations at 0/400/750/1086. The former runtime owner cropped once using those registrations and the shared alpha-bound utility. Extremely low-alpha background specks were excluded from crop measurement; visible shapes were inspected.

These are PNG illustration masters, not SVG paths or a font. The former runtime applied family color and pearl highlights to their neutral faces. See the source-bound [original integration acceptance](../../docs/design/celebration-lettering/crystal-comet-01/INTEGRATION.md); the new multi-angle family owns current behavior.
