# Dialogue portrait generation

Built-in image generation, October 17, 2026. One transparent PNG per speaker. Reference 1: `docs/design/character-chat/bubble-and-avatars-concept.png`; reference 2: each corresponding approved master in `docs/design/star-cast/crystal-glow/characters/`. These are independent dialogue portraits; board materials were unchanged. Original outputs are retained here. Native asset sets use 256×256 technical downsampling via `sips --resampleHeightWidth 256 256` with alpha retained.

## Sunny

```text
Use case: stylized-concept. Asset type: production dialogue avatar, single standalone transparent cutout. Create Sunny, golden amber five-point, welcoming with a warm open smile, large blue-black eyes, for Starfall's approved Crystal Glow character chat. Image 1 is the approved bubble/avatar style reference; image 2 is this character's identity master. One character only, not an expression sheet. Larger expressive face, broad translucent crystal facets, premium soft painted 3D finish, subtle three-quarter turn toward viewer's right while preserving readable silhouette and point count, coherent upper-left warm key light, carefully drawn glossy eyes. Keep the body full and uncropped, centered with 12% clear canvas margin on all sides, full star filling about 76% of square canvas; face optically large enough at 64 points. Preserve each character's distinct silhouette. Transparent background, clean alpha edge; no backdrop, frame, medallion, circle, bubble, text, sparkles, cast ground shadow, props, costume, hands or human body. No floating decoration. Match the appealing enlarged portrait in the reference rather than shrinking a gameplay sprite. The native UI will draw the medallion and speech bubble separately.
```
