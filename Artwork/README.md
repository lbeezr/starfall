# Artwork sources and handoffs

Editable branding sources and the retained crystal production package.

## Start here

Use [AppIcon](AppIcon/README.md) for current branding, [StarCast](StarCast/README.md) for Crystal Glow body sources and packaging, and [Crystals](Crystals/README.md) for the original Debug puzzle. The [runtime cast factory](../docs/design/star-cast/README.md) composes packaged bodies and authored faces.

[Conversation portraits](Dialogue/README.md) retain the six generated dialogue masters and prompts; native 256×256 exports live in the app asset catalog.

[Celebrations](Celebrations/README.md) owns provenance and source registrations for the selected Crystal Comet title/glyph material; packaged PNGs remain in the app asset catalog.

[Crystal Comet sprites](CrystalComet/README.md) extends the selected lettering into the full uppercase/lowercase alphabet, numerals and punctuation at 45 angles. It owns the offline source/build pipeline and sprite-pack handoff; app integration is separate.

[Observatory UI](ObservatoryUI/README.md) owns the dedicated SVG glyphs, generated mode emblems, reusable enamel/brass skins and reproducible exports. The normal app adopts this family for development through `ObservatoryArtwork` and the shared theme. The [game UI system](../docs/design/GAME_UI_SYSTEM.md) owns its contract; exact coverage and canonical delivery status are recorded in the [native evidence](../docs/evidence/observatory-ui-native-2026-10-19/README.md), with inspected appearances in the [capture index](../docs/evidence/observatory-ui-native-2026-10-19/captures.json). Source/export verification remains distinct from native evidence.
