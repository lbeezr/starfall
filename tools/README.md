## Retained payloads

`art-quality/output`, `art-quality/comparison/baseline` (including its asset sets), `art-quality/comparison/self`, and `gameplay-study/results-2026-10-16` contain retained render/comparison or study output. Their owning tool README supplies context; do not insert documentation into baseline payloads or regenerate them as routine cleanup. New raw runs belong under ignored artifacts unless deliberately retained with a source-bound record.
