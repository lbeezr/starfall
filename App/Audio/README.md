# Runtime audio

Four selected quiet-tuck MP3 variations accompany ordinary clears. Two original synthesized WAV cues give large clears and drawn constellations a short attack and rising resolution; reproduce them with `python3 scripts/generate-celebration-audio.py` from the repository root. The generator uses only the Python standard library and contains no third-party samples.

`QuietTuckPlayer` owns one audible voice, mute and interruption cancellation. All six files are bundled by the existing Audio folder resource; ordinary take rotation remains unchanged. See [audio integration](../../docs/design/audio/INTEGRATION.md) for the historical tuck acceptance and [starlight celebrations](../../docs/design/STARLIGHT_CELEBRATIONS.md) for current tier behavior. Saved sound preferences remain authoritative.
